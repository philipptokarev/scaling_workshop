# Результат выполненого задания:

## Модель HeavyFileObject

У модели присутствуют поля uuid, state. UUID - отвечает за уникальный индификатор загруженного файла, который необходимо обработать. State - отвечает за отслеживания статусов файла.

## Job-обработчики

AsyncSendingObjectProcessedJob - эмулирует сообщение из другой системы, который занималась обработкой файла
ObjectProcessJob - помечает, что файл обработан и его можно удалить
ObjectDeleteJob - удаляет все помечанные файлы, используя механизм LeaderElection, через scheduler
раз в 15 секунд

## Heavy Loop

Эмулирует создание нового файла один раз в интервале от 5 до 20 секунд

## Метрики

Добавлены 3 новые метрики: `file_processing_count, file_processed_count, file_deleted_count`
С помощью этих метрики можно будет увидеть кол-во необработанных, обработанных и удаленных
в разрезе одного дня. Также при отслеживании полученных данных можно будет понять,
где большая потеря времени при обработки полученных файлов.
